Copy once.
Paste one at a time.

Sequential Paste turns anything you copy into a queue. Each press of Ctrl+Shift+V pastes the next line, value or spreadsheet cell, so you can fill forms without flipping between windows.

Questions

Good to know.

Does it send my clipboard anywhere?

No. It never connects to the internet. Your text stays in memory on your PC and is gone when you copy something else.

Will it break Ctrl+Shift+V in my browser?

No. The shortcuts only act while you have a list of two or more items loaded. Otherwise they go to the app you're using as normal. You can also pause them from the tray.

A site won't let me paste. Now what?

Switch "Insert items by" to Typing it out. It types each item as keystrokes, which works on most paste-blocked fields.

Why does Windows warn me when I run it?

The app isn't code-signed, which costs money every year, so SmartScreen doesn't recognise it yet. Choose More info, then Run anyway. You can read every line of the source on GitHub.

What does it need?

Windows 10 or 11. The app window uses Microsoft Edge WebView2, which Windows 11 and current Windows 10 already have. Without it, everything still works from the tray menu.

How do I uninstall it?

Settings, then Apps, then Sequential Paste, then Uninstall. The portable version is just one file you can delete.
